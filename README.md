# Roblox Portable

A portable Roblox launcher for Windows. It installs Roblox in its own folder, so your normal Roblox stays untouched. No installer, no .NET needed.

> Unofficial tool. Not affiliated with or endorsed by Roblox Corporation.

## How to use

1. Open the [latest release](../../releases/latest) (**v1.1.0**).
2. Download **RobloxPortable.zip**.
3. Extract it into its own folder (right-click → **Extract All or Extract to**).
4. Run `RobloxLauncherPortable.exe`.
5. Click **INSTALL ROBLOX** and wait for the download to finish.
6. Click **LAUNCH ROBLOX APP** and log in inside the Roblox window.

The full guide, `HOW_TO_USE.txt`, is inside the zip.

### Play from the Roblox website

1. Open the **⋮** menu and click **Use for website launch**.
2. Log in on roblox.com in your browser and click **Play**.
3. The game opens in the portable launcher, already logged in.

### Multiple accounts

Log in to each account in a different browser (or browser profile) and click **Play** in each one. Every game opens in its own window. Keep the launcher open while you play.

### Updating Roblox

When a new Roblox version is out, the big button changes to **UPDATE ROBLOX**. Close all Roblox windows and click it.

## ⋮ Menu

- **Update / Repair**: reinstall the game files (close all Roblox windows first).
- **Open portable folder**: open the `RobloxPortableData` folder.
- **Use for website launch / Stop website launch**: turn the website Play button on or off.
- **Uninstall Portable Files**: delete all portable Roblox files.

## Notes

- Each window's login is wiped when you close it.
- If a game closes right after opening, check `RobloxPortableData\launcher.log`.
- If the original Roblox opens instead, use **Use for website launch**.
